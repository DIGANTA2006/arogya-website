# Arogya Website Gallery Folder Guide

Put images in these folders:

clinic/
- Clinic building photos
- Reception area
- Therapy room
- Waiting area
- Equipment photos

therapy-sessions/
- Therapy activity photos
- Child learning activity photos
- Speech therapy setup photos
- Use only with patient/guardian consent

patients/
- Patient success photos
- Patient with therapist photos
- Use only with written permission

hearing-aids/
- Hearing aid product photos
- Ear mould images
- Hearing test machine images

certificates/
- Doctor/clinic certificates
- Awards
- Training certificates

events/
- Health camp photos
- Awareness program photos
- Clinic events

staff/
- Doctor/therapist/staff photos

Recommended image names:
clinic-front.jpg
therapy-room.jpg
hearing-test-machine.jpg
speech-therapy-session-1.jpg

Do not upload:
- Prescriptions
- Reports
- Aadhaar/PAN
- Phone numbers
- Private patient documents
